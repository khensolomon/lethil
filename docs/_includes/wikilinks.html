{%- comment -%} Resolves [[wiki-links]] in include.text into anchor tags. Supported forms: [[Environment setup]] -> match by title (case-insensitive) [[Environment setup|setup]] -> match by title, custom display text [[python/setup]] -> match by section-key/slug path A resolved link becomes display. An unresolved one becomes … (same as Obsidian showing a broken link). Requires `page_index` in scope (include page-index.html first). CODE IS LEFT ALONE. This include runs on already-rendered HTML, so a page that *writes about* wiki-link syntax — `[[Some page]]` in backticks, or a fenced block showing Obsidian markup — would otherwise have its examples silently rewritten into real links. The text is first split on … pair are processed; everything inside is passed through verbatim. Kramdown renders both inline code and fenced blocks (
) with that tag, so one split covers both.

  Splitting on "[[" then "]]" avoids any regex (Liquid has none). Each odd
  segment after the first split is link-or-tail; we cut it at "]]".
{%- endcomment -%}
