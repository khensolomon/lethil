{%- comment -%} Tools popover in the topbar — the single global route to the tool pages. It replaces the sidebar icon rail, which duplicated the tab strip already at the top of every tool page: the same menu in two places, in two visual languages. One button costs a fixed 30px on any page, so the sidebar keeps its whole height for the section's pages. A disclosure, not an ARIA menu: the contents are ordinary links, so aria-expanded is the honest description and arrow-key navigation would be inventing a widget the user has no reason to expect. Driven by _data/tools.yml, the same source as the tab strip. {%- endcomment -%}
