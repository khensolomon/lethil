{%- comment -%} Generic card grid for apps AND tools/extensions. Driven by front-matter data so markdown files stay markup-free. Called from portfolio.html twice: once for the apps list, once for the tools list, each time passing that list as items and a heading string. Per item: name (required) → links to repo repo (required) destination for the name + art blurb (optional) image (optional) — absent → a monospace "[+]" tile is shown instead. "symbolic" in the filename → rendered as a themed mask. stores (optional) array of {label,url}; absent → a "Source ↗" link. Card children are FLAT (art, name, blurb, links) so CSS grid-template-areas can reflow them: art beside stacked meta on wide screens, art+name on one row with full-width blurb/links on phones (no wasted space under the art). {%- endcomment -%}
