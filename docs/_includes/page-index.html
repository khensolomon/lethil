{%- comment -%} Builds `page_index` — every navigable page across every section, in sidebar order, so other templates can resolve [[wiki-links]] and build the graph without re-walking the collections. Each entry is a string "key|title|url|section_label" (| is safe: titles don't contain it). Kept as strings because Liquid cannot build hashes. Navigability, title fallback, and ordering all come from nav-docs.html, so a wiki-link resolves against exactly the pages the sidebar shows — including pages whose title is inferred from the filename. {%- endcomment -%} {%- assign page_index = "" -%} {%- for meta in site.data.sections -%} {%- include nav-docs.html key=meta.key -%} {%- for row in nav_rows -%} {%- assign pi_f = row | split: "‖" -%} {%- capture pi_entry -%}{{ meta.key }}|{{ pi_f[2] }}|{{ pi_f[3] }}|{{ meta.label }}{%- endcapture -%} {%- if page_index == "" -%} {%- assign page_index = pi_entry -%} {%- else -%} {%- assign page_index = page_index | append: "§" | append: pi_entry -%} {%- endif -%} {%- endfor -%} {%- endfor -%} {%- assign page_index = page_index | split: "§" -%}
